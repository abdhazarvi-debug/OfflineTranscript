# PDF Text Extractor — Android

Mobile application track for the supplied PDF Text Extractor V3. The UI follows the supplied dark navy/blue reference design. This branch is a mobile foundation and must not claim unimplemented OCR/output features as complete.

Architecture: Kotlin + Jetpack Compose + Android document picker + PDFBox Android + Tesseract4Android dependency for offline OCR. The next phase must wire page rendering, word boxes, RTL/LTR geometry reconstruction, retries, outputs and searchable PDF before production release.
